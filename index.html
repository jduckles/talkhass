2013: Paulus Schoutsen releases 0.1 on 17 September. 2017: release 0.37 re-licenses the code under Apache 2.0; Hass.io (now HAOS) arrives the same year. 2018: Nabu Casa is founded to run Home Assistant Cloud and pay contributors. 2024: the Open Home Foundation takes ownership of the code and the brand.

The license matters more than the star count: Apache 2.0 means no one can take the code away, and the foundation means no one can sell the project out from under its users.
